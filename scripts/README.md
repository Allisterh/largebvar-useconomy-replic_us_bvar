# Scripts Directory

This directory contains utility scripts, tests, and examples for the Large Bayesian VAR project.

## Contents:

### Test Scripts
- `test_*.py` - Unit and integration test scripts
- `debug_*.py` - Debugging utilities

### Example Scripts  
- `example_*.py` - Usage examples and demonstrations

### Utility Scripts
- `replicate_paper.py` - Script to replicate paper results
- `var_pipeline.py` - Alternative pipeline implementation

## Usage

Run any script from the project root directory:
```bash
python scripts/test_fast_bayesian.py
python scripts/replicate_paper.py
```
